# Merchants

Outbound links are only the URLs in `data/catalog.json`.

Commission Junction applications are pending. Until `merchants.<id>.cj_click_url` is set, every button is the merchant's own https product page. The shopper id (`{pagetype}-{slug}-{placement}`) is stored on the anchor as `data-sid` and is added to the query string only after a CJ click URL is configured. Scripts must not request `anrdoezrs.net`, `jdoqocy.com`, `tkqlhce.com`, `dpbolvw.net`, `kqzyfj.com`, `emjcd.com`, `awin1.com`, or `linksynergy.com`.

Horizn Studios prices are euros because that shop's public cart currency is EUR. They are not converted to dollars.

No Amazon, eBay, Walmart, Nordstrom Rack, or Sephora links.
