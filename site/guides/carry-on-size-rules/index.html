Carry-on size rules by airline

Airline limits change, and a suitcase's overall size includes wheels and handles when the maker says so. This page quotes only the measurement we could read on the airline's own page.

Delta

Combined length + width + height of baggage must not exceed 45 linear inches (114 cm). Individual length, width and height measurements may not exceed 22” x 14” x 9” (56 cm x 35 cm x 23 cm) respectively. These measurements include any handles or wheels.
